# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful and constructive; no harassment, discrimination or
personal attacks; remember that this project exists for families and their
children, so treat any data about children with the greatest care and never
share it.

Report unacceptable behaviour to the maintainer through the email on the
GitHub profile. Reports are handled confidentially.
